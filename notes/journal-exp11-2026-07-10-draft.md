## Configuration

- **Model:** `/models/llama-3.2-3b-instruct` (node1 path; 28L, 3072h, 24Q/8KV heads,
  llama3 static rope scaling — re-rotation exact, homomorphism assert at load), bf16,
  `attn_implementation="eager"`, single GPU (CUDA_VISIBLE_DEVICES=0), batch=1.
  NOTE deviation: the anamnesis 3B preset says fp16; the exp11 design contract says
  bf16 (matching every kv-rotation experiment) — bf16 used, recorded in run config.
- **Instrument:** anamnesis-pl v3 (`~/luxi-files/anamnesis-pl-exp11`, read-only copy of
  the dev checkout, branch v3-feature-fixes). Signature = `compute_features_v2_from_data`
  with the run_replay_extraction family set (baseline T1/T2/T2.5/T3 + residual_trajectory
  + attention_flow + gate_features + per_head, STFT on, temporal_dynamics off) →
  **2,713-dim v3 FULL space** (the space `factor_directions_3b.npz` FULL_W was fit in).
  Hook surface: all-layer k_proj + sampled-layer gate_proj; no v_proj/q_proj (the 2,713
  set doesn't consume them). Sampled layers [0,7,14,18,21,24,27]; PCA layers
  [7,14,18,21,24]; fp32 feature math.
- **Calibration (read-only, never refit):** positional_means.npz (29×712×3072) +
  pca_model.pkl (legacy pooled dict, 50×3072) — staged to
  `node1:~/luxi-files/kv-rotation/exp11_calibration/`.
  **Layout deviation from the design note:** the spec's `outputs/calibration/` only
  holds the 8B calibration; the 3B artifacts live at
  `anamnesis_exps/phase_0/outputs/calibration/` (where `MODEL_PRESETS["3b"]` points).
  Loaders adapted; pointer note on the anamnesis side corrected.
  Note: max calibrated position is 712 — every exp11 context (P≈4–5k) clamps the
  positional-mean lookup to row 711 under ALL conditions, so the correction is a
  per-layer constant that cancels in Δ. For NAIVE, `remap_positional_means` keeps the
  short-cache case exact anyway (CPU-tested).
- **Bridge:** `src/kvrot/sigbridge.py::replay_extract_cached` — continuation-only
  forward against an injected cache with explicit position_ids/cache_position;
  RawGenerationData byte-compatible with `replay_extract` (T = N−1 rows; attention
  rows over [cache_len + t] columns = the surgered cache, the on-thesis T2.5 surface;
  `prompt_length` = cache length so the extractor's prompt/gen split lands on the
  cache/continuation boundary). Incremental twin (N single-token forwards) provides
  the path floor (b).
- **Substrate, Regime A:** 8 conversations freshly generated by the 3B itself
  (`experiments/exp11_gen_native3b.py`): two seeded personas (Wren/Moss) on the SAME
  weights alternating turns through the chat template, manual nucleus sampling
  (temperature 0.9, top_p 0.95, per-turn seed = (2026+conv)*1000+turn, retries +499),
  ~340-token cap with sentence-trim on cap hits, grown to ≥4800 rendered tokens,
  hand-written openers banked generated=false (the only non-3B text; exp10 convention).
- **Substrate, Regime B:** 4 cells from `data/eval_docs.jsonl` (node1), 4608 tokens,
  exp08 geometry (keep 4 sinks, evict ONE contiguous early block of ef·P tokens, keep
  tail).
- **Conditions per cell:** FULL / ROT (evict → Tier-0 re-rotate → recompact) /
  REC (fresh prefill of identical shortened text) / NAIVE (evict, NO reindex —
  survivors keep original positions; continuation resumes at survivor-max+1 = P).
  ef=0.5 base; dialogue eviction turn-aligned oldest-first (protect system + last 2
  turns, 4 sinks). Continuation: FULL's greedy rollout, N=256, frozen per cell,
  teacher-forced identically under all conditions.
- **Floors:** (a) FULL batched replay twice (numerics); (b) incremental decode-path
  FULL replay (path floor — all ratios reported against this).
- **Sweep (fade curve):** first 2 dialogue cells + first doc cell also run ROT/REC at
  ef ∈ {0.25, 0.75} plus one ROT/REC replay repetition (stability read).
- **Feature-name alignment:** hard-asserted per condition per cell, and against
  FULL_names for the exploratory mode projection.
